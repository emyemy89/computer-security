# Task 1. Simple Synchronous Stream Cipher

Submit your solution for Task 1 here, in this directory. Your solution
should consist of the following files:

* `StreamCipher.java`

Do not rename the file or move it somewhere else. The grading program
expects to find this file here, in this directory.

You may add more files will Java classes if you want, but make sure
that your program compiles correctly with this shell command:

```
$ javac StreamCipher.java
```

## Testing
The directory `example`  contains example files that you can use to
test your implementation.
