# Task 3. RC4

Submit your solution for Task 3 here, in this directory. Your solution should consist of the following files:

* `StreamCipher.java`
* `MyRandom.java`

Do not rename the files or move them somewhere else. The grading program expects to find these files here, in this directory. 

You may add more files will Java classes if you want, but make sure that your program compiles correctly with this shell command:

```
$ javac StreamCipher.java
```
